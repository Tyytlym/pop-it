# 🫧 解压水晶泡泡 (Crystal Bubble)

一个结合了 3D 彩虹水晶质感、高浓度星尘粒子特效与声音合成的交互式解压网页。

**在线体验：** https://你的用户名.github.io/你的仓库名/

---

## ✨ 功能特性

- **极致解压**：点击或滑动屏幕，瞬间戳破立体水晶泡泡。
- **自动模式**：解放双手！点击按钮即可让泡泡自动引爆，支持自由调节爆炸频率。
- **双形态爆破**：泡泡引爆时，随机触发“星尘爆炸”或“液体流淌”两种粒子特效。
- **顶级视觉**：基于 Three.js，拥有真实球体高光、彩虹薄膜干涉以及 Bloom 辉光特效。
- **沉浸音效**：使用 Web Audio API 动态合成清脆的破裂声与水流声。

---

## 💻 本地运行

无需安装环境，直接双击打开 `index.html` 即可。
*(注：项目依赖 Three.js CDN，请保持网络畅通)*
